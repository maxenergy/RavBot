### ✅ 任务 #1: 修复搜索功能报错 (1-2小时)

**问题**: web_search 返回内容过大导致 API 502 错误

**解决方案**:
- 限制 web_search 返回内容大小
  - 每个结果最多 500 字符
  - 总共最多 5000 字符
- 改进 GitHub 工具错误处理
  - 返回 JSON 格式错误信息
  - 避免长错误消息

**修改文件**:
- `src/tools/tool_registry.cpp`
  - web_search_tool - 添加内容大小限制
  - github_search_repos_tool - 改进错误处理

**效果**:
- ✅ 防止 API 502 错误（Improperly formed request）
- ✅ 搜索功能更稳定
- ✅ 错误信息更友好

**Git 提交**: a60b3b3

### ✅ 任务 #2: 集成向量索引到 Agent Loop (4.5小时)

**问题**: 向量数据库为空，缺少自动索引机制

**解决方案**:
- 添加 EmbeddingManager 成员变量到 AgentLoop
- 在 ProcessMessage 和 ProcessMessageStream 中自动索引消息
- 索引用户消息和 assistant 响应
- 添加元数据（role, session, timestamp）
- 错误处理不影响主流程

**修改文件**:
- `include/ravbot/core/agent_loop.hpp`
  - 添加 embedding_manager_ 成员变量
  - 添加 SetEmbeddingManager() 方法
- `src/core/agent_loop.cpp`
  - 添加 embedding_manager.hpp 头文件
  - 在返回前索引消息

**索引逻辑**:
```cpp
// 索引用户消息
user_msg_id = session_key + ":user:" + timestamp
embedding_manager_->IndexText(user_msg_id, message, metadata)

// 索引 assistant 响应
assistant_msg_id = session_key + ":assistant:" + timestamp
embedding_manager_->IndexText(assistant_msg_id, response, metadata)
```

**元数据格式**:
```json
{
  "role": "user" | "assistant",
  "session": "session_key",
  "timestamp": 1773569010172
}
```

**效果**:
- ✅ 向量数据库自动填充
- ✅ 语义搜索可用
- ✅ 长效记忆增强
- ✅ 性能影响最小

**Git 提交**: 356264d
