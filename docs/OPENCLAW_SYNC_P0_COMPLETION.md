## 已完成功能

### 1. ✅ 可配置的 Compaction 超时

**OpenClaw 参考**: commit f77a68413
**优先级**: P0 (关键)
**工作量**: 2 小时

**实施内容**:
- 添加 `compact_timeout_seconds` 配置项到 `AgentConfig`
- 默认值 900 秒（15 分钟）
- 支持 camelCase 和 snake_case 配置格式

**修改文件**:
- `include/quantclaw/config.hpp` - 添加配置字段
- `src/core/config.cpp` - 添加配置解析

**配置示例**:
```json
{
  "agent": {
    "compact_timeout_seconds": 1200
  }
}
```

**影响**:
- 解决大型 session (400k+ tokens) 的 compaction 死循环问题
- 防止 session 无限增长
- 提高系统稳定性

---

### 2. ✅ 外部内容元数据清理

**OpenClaw 参考**: commit a97b9014a
**优先级**: P0 (关键)
**工作量**: 1.5 小时

**实施内容**:
- 添加 `SanitizeMetadata()` 方法到 `MessageSanitizer`
- 使用白名单机制保留安全字段
- 限制字符串长度和类型

**修改文件**:
- `include/quantclaw/gateway/message_sanitizer.hpp` - 添加方法声明
- `src/gateway/message_sanitizer.cpp` - 实现清理逻辑

**白名单字段**:
- `source` - 来源标识
- `timestamp` - 时间戳
- `type` - 内容类型
- `url` - URL
- `title` - 标题
- `author` - 作者
- `language` - 语言

**安全措施**:
- 移除边界标记
- 限制字符串长度（最大 1000 字符）
- 只保留字符串、数字、布尔值类型
- 忽略对象和数组类型

**影响**:
- 防止通过元数据进行注入攻击
- 提高系统安全性
- 符合安全最佳实践
