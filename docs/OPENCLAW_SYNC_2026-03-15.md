## 关键更新分类

### 1. 配置和性能优化

#### 1.1 可配置的 Compaction 超时 (#46889)

**提交**: f77a68413
**重要性**: ⭐⭐⭐⭐⭐ (高)

**问题**:
- 硬编码的 5 分钟 compaction 超时导致大型 session 进入死循环
- Session 无限增长，compaction 反复失败

**解决方案**:
```typescript
// 新增配置项
agents.defaults.compaction.timeoutSeconds = 900  // 默认 15 分钟
```

**影响**:
- 支持最多 ~400k tokens 的 session
- 锁定时间与 compaction 时间同步
- 防止锁过期导致的并发问题

**RavBot 迁移**:
- ✅ **需要迁移**: RavBot 也有 compaction 功能
- 📍 **位置**: `src/core/agent_loop.cpp` 或配置系统
- 🔧 **实现**: 添加 `compaction.timeoutSeconds` 配置项
