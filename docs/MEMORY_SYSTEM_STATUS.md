## 📊 系统概览

### 双层记忆架构

QuantClaw 采用双层记忆系统：

1. **结构化记忆** - MEMORY.md 文件
   - 存储关键事实和用户偏好
   - 人类可读的 Markdown 格式
   - 手动或 Agent 通过 memory_write 工具更新

2. **语义记忆** - 向量数据库
   - 自动索引所有对话消息
   - 支持语义搜索和相似度检索
   - 使用 HNSW 索引实现高效查询
